Benchmark: correctness first, then speed

The score is relative, from 0 to 100. It averages 10 numbers: 5 throughput figures (read, list, write and mixed requests per second, plus successful writes per second under contention), each scored as 100 × value ÷ best, and the 5 matching p99 latencies, each scored as 100 × best ÷ value. A 50 means about half the leader across those 10. Any lost update, leak or error rate above 1% would set a score to zero. None did.

Known issues and gaps

IssueStatus
Python returned a connection reset instead of 413 for a 2.2 MB body once in CI (1 of 2 runs)Not reproduced locally in 20 runs. Transport profile.
Python and PHP run on development HTTP servers, with weak request framing (conflicting Content-Length and Transfer-Encoding)Found by Grok's red team. Use a production server.
Hidden notes answer about 30 µs slower than missing ones on Deno and PHPTiming side channel. Not yet pinned by a rule.
