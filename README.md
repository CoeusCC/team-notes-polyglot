# Team Notes, built spec-first

This is a REST backend for a note-taking service shared among small teams. It is built **spec-first**:
- an OpenAPI contract
- ratified acceptance criteria
- a language-neutral conformance suite

It is delivered in **gated tiers**, so there is always a working, demoable service before more ambitious work starts.

> 🚧 Work in progress. See [`docs/PLAN.md`](docs/PLAN.md) for the plan, [`docs/build-digest.md`](docs/build-digest.md) for progress, and [`docs/adr/0001-architecture.md`](docs/adr/0001-architecture.md) for the architecture decision.

The quickstart, the design choices and what we'd change with more time come at Gate 1.
